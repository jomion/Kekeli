KEKELI — Lot du 11 septembre 2026
==================================

Ce lot répond à la demande en 8 points concernant les devoirs, les notes et
l'éditeur de séance. Voici ce qui a changé, fichier par fichier.

1) Correction du bug bloquant "invalid input value for enum type_bloc:
   correction"
   -----------------------------------------------------------------
   La valeur 'correction' avait été ajoutée côté JS pour le nouveau bloc
   Correction, mais jamais côté base de données. Corrigé directement en
   base (migration Supabase appliquée immédiatement, comme convenu) :
   plus aucune séance ne peut planter à l'ajout d'un bloc Correction.

2) Cartes de devoirs cliquables, organisées par matière
   -----------------------------------------------------
   Fichiers : js/devoirs-notes-rendu.js, js/pages/eleve-devoirs-notes.js,
   js/pages/parent-devoirs-notes.js, js/pages/enseignant-devoirs-notes.js,
   css/style-public.css
   Les cartes "Publiés / Brouillons / En retard / ..." ne se contentent
   plus d'afficher un chiffre : un clic déroule directement la liste des
   devoirs concernés, regroupés par matière, pour l'élève, le parent et
   l'enseignant.

3) Suppression et modification d'un devoir, même déjà publié
   -----------------------------------------------------------
   Fichiers : js/devoirs-notes-rendu.js, js/pages/enseignant-devoirs-notes.js,
   js/pages/admin-devoirs-notes.js
   Nouveaux boutons "✏️ Modifier" et "🗑️ Supprimer" sur chaque devoir, dans
   les vues enseignant et admin, quel que soit son statut (brouillon ou
   publié).

4) Barème pour la correction automatique + note manuelle pour les exercices
   libres des devoirs
   ---------------------------------------------------------------------
   Fichiers : js/editeur/devoir-blocs.js, js/pages/eleve-devoir-rendu.js,
   js/devoirs-notes-rendu.js
   Le bloc "Exercice" d'un devoir fonctionne maintenant comme celui d'une
   séance (texte libre + bloc Correction), avec un champ HTML brut en
   option (voir point 7). L'élève rend une réponse rédigée, l'enseignant la
   corrige à la main et lui attribue une note — les blocs Quiz/Évaluation/
   Activité gardent, eux, leur barème et leur correction automatique
   inchangés.

5) Affichage des notes réduit par défaut
   ---------------------------------------
   Fichiers : js/devoirs-notes-rendu.js, js/pages/eleve-devoirs-notes.js,
   js/pages/parent-devoirs-notes.js, css/style-public.css
   Les notes s'affichent maintenant en résumé compact, une ligne par
   matière (dernière note/appréciation), dépliable pour voir le détail
   complet — fini l'affichage encombrant de toutes les notes d'un coup.

6) Bouton "🚀 Passer aux activités" dans l'éditeur de séance
   -----------------------------------------------------------
   Fichier : js/pages/editeur-seance.js
   Un nouveau bouton, à côté de "🧠 Générer avec l'IA", permet de choisir
   les blocs à créer (Consigne, Activité, Quiz, Évaluation) et le palier :
   l'IA génère automatiquement leur contenu (questions + corrigé) à partir
   de ce qui est déjà rédigé dans la séance, sans avoir à créer les blocs
   un par un.

7) HTML brut dans les exercices (séance et devoir)
   ---------------------------------------------------
   Fichiers : js/editeur/blocs.js, js/editeur/devoir-blocs.js,
   js/pages/editeur-seance.js, js/pages/eleve-devoir-rendu.js, css/style.css
   Une case à cocher sur le bloc "Exercice" (séance ET devoir) permet de
   basculer en mode "HTML brut" pour coller une mise en page complexe
   (tableau personnalisé, schéma...) — affichée à l'élève dans un cadre
   isolé, sans script exécutable, comme le bloc "HTML libre" existant.

8) Nouveau bloc "Problème" (mathématiques) avec tableau de résolution
   ----------------------------------------------------------------------
   Fichiers : js/editeur/blocs.js, js/pages/editeur-seance.js,
   js/pages/eleve-seance.js, js/apercu-blocs-seance.js, css/style.css,
   css/style-public.css
   Nouveau type de bloc "🧮 Problème" pour l'éditeur de séance :
   - un énoncé rédigé avec l'éditeur riche habituel ;
   - trois champs à renseigner avant la résolution : Données, Inconnues,
     Autre ;
   - un tableau de résolution où l'enseignant ajoute une ligne par étape :
     colonne 1 la phrase de solution / l'équation posée, colonne 2 le
     résultat trouvé, colonne 3 l'opération posée.
   La colonne 3 propose deux gabarits : "Opération posée" (addition,
   soustraction, multiplication — les chiffres s'alignent automatiquement
   grâce à une police à chasse fixe alignée à droite, sans décalage) et
   "Division posée" (dividende / diviseur / quotient présentés selon la
   disposition classique, avec les étapes de soustraction en dessous,
   alignées de la même façon). Ce bloc est en lecture seule côté élève
   (pas de soumission ni de note automatique) — l'enseignant rédige
   lui-même la résolution modèle.
   Remarque : ce nouveau bloc a nécessité une migration Supabase (valeur
   'probleme' ajoutée à l'énumération des types de blocs), déjà appliquée
   en base au moment de cette livraison.
