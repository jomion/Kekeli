KEKELI — Livraison : formatage riche des blocs d'activité + 5 nouveaux types de question
==========================================================================================
Date : 11 septembre 2026

CE QUI CHANGE
--------------

1) FORMATAGE DE TEXTE ENRICHI (gras, italique, souligné, listes, couleurs, alignement,
   police, taille) désormais disponible à deux endroits dans les blocs d'exercice/quiz/
   évaluation/activité :
   - la « Consigne générale » du bloc (comme demandé) ;
   - l'énoncé de CHAQUE question (comme demandé : « le formatage est valable pour la
     consigne et pour le contenu de l'activité »).

   Exception volontaire : les 3 types de question où l'énoncé contient directement le
   texte à trous ou les mots à manipuler (texte à trous classique, texte à trous à
   glisser-déposer, sélection de mots dans un texte) gardent un énoncé en texte simple,
   car le formatage riche casserait le repérage automatique des mots/trous. Pour ces
   3 types, la consigne générale du bloc reste, elle, en formatage riche.

   Attention : si un texte a été mis en forme (gras, couleur...) puis que le type de
   question est ensuite changé vers un des 3 types « texte simple » ci-dessus, les
   balises de mise en forme ne seront plus interprétées et pourraient apparaître telles
   quelles. Il est recommandé de choisir le type de question avant de rédiger un énoncé
   très formaté.

2) NOUVEAU TYPE : « Intrus » (choix parmi plusieurs mots proposés)
   Une ou plusieurs séries de mots ; l'élève doit repérer, dans chaque série, le mot qui
   n'appartient pas au thème commun. Exemple (celui que vous avez donné) :
   « fièvre — douleur — médicament — ballon » (l'intrus est « ballon »).
   Plusieurs séries peuvent être ajoutées dans une seule question.

3) NOUVEAU TYPE : « Réponse numérique / calcul »
   L'élève saisit un nombre ; vous définissez la bonne valeur et une tolérance
   (utile pour les résultats avec décimales ou approximations acceptées).

4) NOUVEAU TYPE : « Sélectionner des mots dans un texte »
   Le texte de l'énoncé est découpé automatiquement en mots cliquables ; l'élève clique
   sur les mots qu'il juge corrects (ex : repérer les verbes d'une phrase).

5) NOUVEAU TYPE : « Vrai / Faux avec justification »
   En plus de Vrai/Faux, l'élève doit rédiger une justification. La note est calculée
   pour moitié automatiquement (bonne/mauvaise réponse) et pour moitié par l'IA qui
   évalue la qualité de la justification (comme pour les réponses longues).

6) NOUVEAU TYPE : « Glisser-déposer les mots dans le texte »
   Comme le texte à trous, mais l'élève doit faire glisser les bons mots depuis une
   banque de mots proposée (qui peut contenir des mots pièges) vers les trous du texte,
   au lieu de les taper au clavier. Fonctionne aussi au clic (tablette/tactile) pour les
   classes qui n'ont pas de souris.

CE QUI NE CHANGE PAS
---------------------
- Les 9 types de question existants (QCM, QCM multiple, Vrai/Faux, réponse courte,
  réponse longue, texte à trous, remise en ordre, association, classement) fonctionnent
  exactement comme avant.
- Les corrigés restent invisibles côté élève dans tous les cas (sécurité inchangée).
- Aucune donnée existante n'est modifiée par cette livraison ; tout ancien contenu
  continue de s'afficher normalement.

CÔTÉ SERVEUR (déjà en ligne, rien à faire de votre part)
----------------------------------------------------------
La fonction de correction automatique (Edge Function « corriger-exercice ») a été mise à
jour et déployée pour corriger automatiquement les 4 nouveaux types auto-corrigeables
(Intrus, Réponse numérique, Sélection de mots, Glisser-déposer) et pour noter le type
« Vrai/Faux avec justification » (moitié automatique, moitié IA). Aucune action requise :
c'est déjà actif.
