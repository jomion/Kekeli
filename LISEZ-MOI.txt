KEKELI — Correctif : bloc « HTML libre » manquant
====================================================
Date : 11 septembre 2026

CE QUI S'ÉTAIT PASSÉ
----------------------
Vous aviez signalé ne plus voir le bloc permettant d'entrer du HTML personnalisé
dans certains cas. Vérification faite directement dans la base de données :
3 blocs de ce type existent bel et bien (dans les séances « Tableau de
numération décimale », une division posée, et les symboles de circuit
électrique), avec leur contenu HTML intact — rien n'a été perdu côté données.

En revanche, le code qui gère ce type de bloc (« html_libre ») n'existait
dans aucun des fichiers déjà livrés sur ce projet : ni dans l'éditeur, ni
dans l'affichage élève, ni dans l'aperçu admin. Résultat concret : dans
l'éditeur, ces 3 blocs s'affichaient comme « Type de bloc non reconnu » (plus
moyen de les modifier), et côté élève leur contenu n'apparaissait tout
simplement plus (bloc vide).

CE QUI EST CORRIGÉ
--------------------
Le bloc « 🌐 HTML libre » est de retour dans la liste des types de bloc de
l'éditeur, avec une grande zone de texte pour coller un document HTML complet
(avec ses propres balises <style>, tableaux, SVG...).

Affichage : ce code s'affiche désormais à l'élève (et dans l'aperçu élève de
l'éditeur, et dans l'aperçu compact des listes admin/enseignant) dans un
cadre bien isolé du reste de la page — c'était nécessaire techniquement,
car le code que vous collez contient souvent ses propres réglages de mise en
page (par exemple une couleur de fond appliquée à « body ») qui, sans cette
isolation, s'appliqueraient à TOUTE la page du site au lieu de rester
confinés au bloc. Ce cadre peut être agrandi à la main (poignée en bas à
droite) si le contenu est plus grand que prévu.

Sécurité : par précaution, aucun script ne peut s'exécuter à l'intérieur de
ce cadre — seuls le texte, les couleurs, les tableaux, le SVG etc. s'affichent
normalement. Ce bloc reste donc adapté à des schémas/tableaux personnalisés
statiques, pas à du contenu qui nécessiterait d'exécuter du code.

Vos 3 blocs existants sont réapparus tels quels, sans que vous ayez besoin de
les recréer.

FICHIERS MODIFIÉS DANS CE LOT
-------------------------------
- js/editeur/blocs.js
- js/pages/editeur-seance.js
- js/pages/eleve-seance.js
- js/apercu-blocs-seance.js
- css/style.css

À NOTER
--------
Comme ce code n'avait jamais été livré via une de nos zips (il avait dû être
ajouté d'une autre façon), il a fallu le reconstruire à partir du contenu
réel déjà enregistré en base plutôt que de simplement le restaurer à
l'identique — le fonctionnement (zone de texte + cadre isolé) est cohérent
avec le reste du site, mais si le bloc fonctionnait un peu différemment avant
(par exemple une hauteur de cadre calculée automatiquement), dites-le-moi et
j'ajusterai.
